Notes
- `.ai` files open in Illustrator/Inkscape and render directly as PDF (`gs`, `pdftocairo`).
- The data-trace panels in 4/6/7/8/9 are regenerated by `code/figures_composite/`;
  the schematic panels (Figs 1, 3, and Fig 7 panel A) come from these sources.
- For the final paper figures, transparency is removed (opaque fills / vector) so the
  figures render reliably across viewers.

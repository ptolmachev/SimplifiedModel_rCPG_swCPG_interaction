# rCPG–swCPG interaction model

Computational model of the synaptic interaction between the respiratory (R-CPG)
and swallowing (Sw-CPG) central pattern generators, together with the LaTeX
source of the accompanying paper.

## Layout

```
code/    Python model, Hydra configs, and figure-generation scripts
         (see code/README.mkd for model details and run instructions)
paper/   LaTeX manuscript (synced with Overleaf via git subtree)
```

`code/data/` and `code/img/` hold locally generated simulation outputs and
figures; they are gitignored and regenerated by the scripts.

## Running the code

The package resolves all paths relative to its own location, so put `code/` on
the Python path:

```bash
cd code
PYTHONPATH=$PWD python rCPGswCPG/run_model.py        # or: pip install -e rCPGswCPG
```

## Paper sync (Overleaf)

`paper/` is a git subtree of the Overleaf project. To sync:

```bash
git subtree pull --prefix=paper overleaf master --squash   # Overleaf -> repo
git subtree push --prefix=paper overleaf master            # repo -> Overleaf
```

(`overleaf` = remote `https://git.overleaf.com/<project-id>`, authenticated with
an Overleaf git token.)
